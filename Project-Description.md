## Project Topic Area

Software Application / Interactive Polling Platform

The project will be a modern interactive polling application inspired by Nintendo's discontinued Wii Everybody Votes Channel. Users will be able to answer polls, view voting results and statistics, and compare their responses with other users. The project will recreate the simple and engaging concept of the original Everybody Votes Channel while adding new features and adapting it for a modern platform.
