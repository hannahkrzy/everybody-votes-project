## Project Topic Area

Software Application / Interactive Polling Platform

Everybody Votes is an interactive polling web application inspired by Nintendo's discontinued Wii Everybody Votes Channel. Users will be able to answer polls, view voting results and statistics, and compare their responses with other users.

The application will support guest voting, registered accounts, and administrator-created polls. Additional planned features include predictions, voting history, personal statistics, and optional demographic comparisons with privacy protections.

The goal is to recreate the simple and engaging polling experience of the original Everybody Votes Channel while adapting it for a modern, accessible, and privacy-conscious web platform.
